# 家庭資產管理系統 v7.1 Ultimate — 視覺清晰度更新

本更新只調整介面顯示，不更動資料結構與既有紀錄。

## 本次修改
- 黑底介面的按鈕、選單、展開區與標籤提高文字對比。
- 「顯示範圍」未選取按鈕改為深色底＋白字；選取項目改為金色底＋黑字。
- 四張個人卡片統一黑底金框，不再使用四種底色。
- 移除個人名稱前的人像圖示。
- 個人卡片只有增減數值依正負顯示綠／紅色，其他文字固定高對比白色／金色。
- 保留現有 GitHub 永久保存、備份、匯入／匯出與所有統計功能。

## 更新方式
只需要覆蓋 GitHub 中的 `app.py`（若 requirements.txt 沒變可不動）。
**不要覆蓋 `data.csv`、`config.json` 或 `backup/`。**
